# Suspicious_Log_Detector

## Objective

This Linux projects focused on creating a basic log detector Bash script to analyze failed and succesful log-in logs by searching for a count of failed and sucessful log-in attempts and their IP addresses.

### Skills Learned

- Basic log detector
- Improving skills in Bash scripting
- Gathering informations from logs
- Troubleshooting errors

### Tools Used
- mkdir
- cd
- touch/nano
- grep (-ic, -i = ignore case, -c = count)
- | (pipe)
- $VARIABLES
- awk (for finding certain word on the line)
- sort
- uniq -c
